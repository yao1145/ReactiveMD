# CM6 可选源码编辑器实施记录

基线：`047b547`。本轮开始时工作区干净，前两轮优化已提交。本计划依据已确认的六阶段方案实施；保留旧 textarea 入口，通过独立 CM6 入口验证收益。

## 顺序与所有权

1. 主代理：增加通用 EditorSurface 操作/订阅接口，让工具栏和作者面板兼容两种编辑表面；旧接口保持兼容。
2. Claude Code 子代理 a63bec78 原定负责源码坐标适配；CLI 启动后因认证 401 阻塞，已按 ID 停止。主代理接管实现与测试，未修改认证或 provider 配置。
3. 主代理：独立 CM6 组件、构建入口、按需样式和受控值/历史/文档切换；挂载一次 EditorView，显示区域由 CM6 管理。
4. 主代理：接入同版本作者分析及装饰、诊断、事务回调和现有源码补丁恢复；避免渲染时重复语义编译。引用列表采用有界呈现。
5. 主代理：保留预览 DOM 与运行时，沿用屏幕离屏布局；本批验证状态、锚点、搜索、选择和打印，不默认启用卸载式预览虚拟化。
6. 主代理：浏览器原生输入、软换行、长行、选区与历史、受控更新、源码偏移、SSR/包边界，以及旧编辑器/CM6 同条件性能对照。完成后记录实际数据和仍有的限制。

## 接口约束

- 新入口拟为 `reactive-md/editor/codemirror`；基础入口及旧编辑器不包含 CM6 模块。
- 通用操作包括读取源码/选区、焦点、定位和事件订阅。CM6 不提供伪造的 textarea；旧 `getTextarea()`/`textareaRef` 保持旧入口专有。
- 原始源码使用 UTF-16 范围。坐标适配保留未修改的 LF/CRLF/CR、BOM 与 emoji；新插入换行使用文档首个换行样式。
- 工具栏、格式化和重命名作为单个撤销单元；CM6 编辑器只使用 CM6 历史。受控回传确认不得重复替换文档。
- Worker 结果遵守源码修订号和选项签名；权限改变、基线失效按既有完整恢复路径处理。
- 不自动提交、推送或改变 Demo 的默认编辑器；本轮为可选实现和验证。

## 验证门槛

源码 DOM 随视口和缓冲区变化；输入反馈与预览完成分别测量。正确性包括中文组合事件、CRLF/BOM/UTF-16、焦点、搜索、复制范围、重置与撤销、只读/禁用、缓存和销毁。性能结论以实际样本为准，不预先承诺统一提速比例。

## 完成记录

编辑器、共享 Worker 分析、事务提示、作者列表分页和包入口已实现。用户随后明确要求将 CM6 设为默认、恢复旧配色、修复缺失高亮并提交，取代初始计划中的默认值和提交约定。生产 Demo 已验证默认 CM6 的原生输入及图片粘贴，旧入口可显式选择。原生输入对照及 2000 次连续输入结果见 [实施报告](codemirror-editor-2026-10-29-ch.md)。物理输入法、移动键盘及辅助技术保留为目标设备验收；预览继续保留 DOM。
