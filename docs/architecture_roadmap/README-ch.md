近期按“固定基线 → 单次编译 → 局部恢复 → 执行与宿主一致 → 包边界 → Demo 迁仓 → 编辑器迁仓”推进。三仓库是目标维护形态，公开包消费验证是迁移前提。

长期继续围绕可嵌入的交互文档系统发展：共享语言语义、版本化组件与主题契约、完整作者工作流和可验证分发。原时间表由近期规划的阶段验收替代；后续能力按真实使用需求推进。
