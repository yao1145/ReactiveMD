# 图表交互验收 Demo

在 ReactiveMD 引擎仓库运行：

```powershell
npx vite --config examples/chart-interactions/vite.config.ts
```

打开 http://127.0.0.1:5201/。

独立 React/SVG 原型，使用 default theme 的实际颜色变量和现有 Motion 依赖。交互设计参考 Bklit UI 的共享读数、系列聚焦和短过渡思路，代码为本地原型实现。尚未接入 RMD 的 `ChartView`、数据绑定与导出。

验收顺序：

1. 在折线、面积图内移动，检查交叉线和同轮各系列读数；柱状图悬浮单根柱仅读取该条数据，散点图定位最近数据点，饼图显示扇区占比。
2. 悬浮或聚焦图例查看系列高亮，点击隐藏或恢复系列；至少保留一个系列。
3. 切换数据 A/B，拖动响应强度，检查 200ms 数据过渡；数值直接更新，无数字滚动。遵循系统减少动态效果设置。
4. 检查浅色、深色与窄屏。聚焦图表可用方向键读数，Escape 关闭提示；下方数据表可核对当前值。

当前原型使用固定 0–100 纵轴和直线连接，便于比较交互。生产接入时再适配现有坐标域、缺失值、选择写回、静态模式和离线导出。
