这个实例使用正式 default theme 和真实 RMD runtime，包含滑块、区间滑块、开关、复选框、分段选择、下拉选择、日期、折叠说明及代码复制。

在核心仓库运行：

```powershell
npx vite --config examples/default-ui/vite.config.ts
```

打开 http://127.0.0.1:5200/。

建议依次验收：

1. 拖动单／双滑块，确认数字直接更新，边框清楚，摘要同步变化。
2. 点击分段选项、开关和折叠说明，确认动效快速，键盘也能操作。
3. 选择课程和日期，切换深色，检查弹层颜色及中文文案。
4. 点击“加载一组实验参数”，确认控件响应外部更新。
5. 清空记录人后移开焦点，查看校验提示；点击实验参数面板的“恢复默认”，检查值和展开状态复位。
6. 切换静态预览，确认当前数值仍可阅读；返回交互后继续操作。
7. 切换主文档明暗模式，右侧独立文档应保持浅色，其他主题保留原生控件。
8. 检查长选项卡、分段选项、下拉菜单、折叠标题和徽标：超长文字省略显示，悬停或聚焦时可查看全文，Escape 关闭提示。

源文档是 `example.rmd`；示例通过公开包入口调用编译器和渲染器。开发配置在源码仓库中使用当前源码，在已安装的包中使用公开导出。
