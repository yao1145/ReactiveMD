# Feature tours / 功能演示

The Playground has a short [Quick start](../pricing.reactive.md) and six feature tours. Each tour opens with a suggested interaction, develops one example and ends with expandable source snippets. Choose Show source to edit the whole document. [Component reference](../gallery.reactive.md) and [Errors & debugging](../diagnostics.reactive.md) are available from the reference menu.

Playground 按“快速体验 + 六个功能馆”组织。每馆开头给出明确操作，围绕一个案例展开，结尾可以查看关键源码。点击“显示源码”可编辑完整文档。“组件查阅”和“错误与调试”位于辅助菜单。

The data tour uses four shared expense parameters in its summaries and visualizations. Table filtering affects only that table. It demonstrates local arithmetic and chart presentation.

统计馆的合计和图表共用四个费用参数，表格筛选仅影响该表。示例演示本地数值计算与图表展示。

Each source is a complete document using the public local interaction syntax. The original [standalone examples](../README.md) remain available for smaller snippets and component regression checks.
