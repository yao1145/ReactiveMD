# Feature tours / 功能演示

The Playground has a short [Quick start](../pricing.reactive.md) and six feature tours. Each tour opens with a suggested interaction, develops one example and ends with expandable source snippets. Choose Show source to edit the whole document. All 43 components are demonstrated within these six scenarios. [Errors & debugging](../diagnostics.reactive.md) is available from the auxiliary menu.

Playground 按“快速体验 + 六个场景”组织。每个场景开头给出明确操作，围绕一个案例展开，结尾可以查看关键源码。点击“显示源码”可编辑完整文档。43 种组件分布在这六个场景中，“错误与调试”保留在辅助菜单。

| Feature / 功能 | English source | 中文源码 | Try this / 操作提示 |
| --- | --- | --- | --- |

The data tour uses four shared expense parameters in its summaries and visualizations. Selecting a category links the table and all charts; filtering affects only that table. It demonstrates local arithmetic and chart presentation.

统计馆的合计和图表共用四个费用参数，项目选择在表格与图表间联动，表格筛选仅影响该表。示例演示本地数值计算与图表展示。

Each source is a complete document using the public local interaction syntax. The original [standalone examples](../README.md) remain available for smaller snippets and component regression checks.
